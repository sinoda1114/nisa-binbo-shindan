# NISA貧乏診断

https://nisa-binbo-shindan.vercel.app

ログインは不要です。回答は保存しません。GitHub の `main` への push が、この URL の本番になります。

いくつかの質問に答えると、NISAの使い方で非課税の恩恵を取りこぼしていないかを「損している」「危うい」「概ね良い」で示します。教育目的の目安です。投資助言でも税務助言でもありません。銘柄は勧めません。税額は計算しません。回答は保存しません。

公開されている金融庁の制度として、つみたて投資枠は年120万円、成長投資枠は年240万円、合計は年360万円です。未使用の年間枠は翌年に繰り越せません。生涯の非課税保有限度額は1,800万円で、うち成長投資枠は1,200万円までです。

## 動かす

```bash
npm install
npm test
npm run dev
```

表示された URL をブラウザで開きます。`npm run build` は本番用の静的ファイルを `dist` に出します。

## 金融リテラシー診断（仮）

タイトルは仮です。正式な名前は未定です。

開始画面で、NISA貧乏診断とは別に選べます。見るのは、日本の個人向けの制度の数字、口座の種類、税金の扱い、よくある誤解です。NISAの使い方の取りこぼしを判定する診断とは別です。銘柄や金額は勧めません。税額は計算しません。

結果のシェアは、見えている結果の紙を画像にしてコピーします。NISA貧乏診断も同じです。X、LINE、Threadsは、その画像をコピーしてから結果をシェアします。シェアのURLに画像は載せず、投稿文にもサイトのURLは入れません。Facebookの共有はページURLが無いと空になるので、投稿先には入れていません。リンクのコピーは残しています。回答の生データは、画像にもリンクにも足しません。
